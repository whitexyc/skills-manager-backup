# Agent 活动日志

> 📋 本文件记录所有 Agent 的**按模块按阶段**活动，是阶段交接的硬性校验之一。
> 粒度规则：**每模块每阶段 1 行**（PLAN/CODE/REVIEW/TEST 交接各 1 行），不逐动作记录。
> **单行 ≤200 字符**：超长结论写 specs/ 对应报告或 `memory/logs/<role>/`，本行只留摘要+指针。
> 历史迭代归档到 `memory/archive/`（见 `docs/rules/memory-rules.md` §3.5），入场只读热区。
> 新 Agent 入场时，先读本文件了解各模块各阶段的最近进展。

## 动作类型标签

| 标签 | 含义 | 典型 Agent |
|------|------|-----------|
| `[PLAN]` | 需求拆解、计划制定 | Planner |
| `[CODE]` | 编码实现 | Developer |
| `[BUILD]` | 编译构建 | Developer |
| `[REVIEW]` | 代码审查 | Reviewer |
| `[ADR]` | 架构决策记录 | Planner / Reviewer |
| `[TEST]` | 编写/运行测试 | Tester |
| `[REGRESSION]` | 回归测试 | Tester |
| `[HANDOFF]` | 阶段交接（通知下一角色） | 任意 |
| `[CONTEXT]` | 更新共享记忆库 | 任意 |
| `[BLOCKED]` | 遇到阻塞 | 任意 |
| `[UNBLOCKED]` | 阻塞解除 | 任意 |
| `[ESCALATE]` | 申请放宽重试/轮次上限（存在进展证据时向 Planner/team-lead 提出） | 任意 |
| `[CORRECT]` | 更正之前的记录 | 任意 |
